Prerequisites & Setup


Ensure you have a local installation of Jupyter Notebook or JupyterLab.
Create a folder named ./docs in the same directory as your notebook file.
Place one or more PDF documents inside the ./docs folder.

Step 1: Install Dependencies (Run in Notebook Cell)
Open a new cell in your Jupyter Notebook.

Step 2: Core Code Execution (Run in Subsequent Cells)
Copy the provided Python script and paste it into one or more subsequent cells. The code will perform the following steps automatically:

Imports: Import all necessary libraries (os, re, pdfplumber, pandas, faiss, SentenceTransformer, pipeline). NOTE: Specify the file path for input

Data Loading: Read all PDF files from the ./docs folder and extract text page by page.

Chunking: Split the extracted text into overlapping chunks (currently 5000 words).

Model Download (1): Automatically download the SentenceTransformer model: all-MiniLM-L6-v2 (≈90MB).

Embedding & Indexing: Convert all text chunks into 384-dimensional vectors and build the FAISS (in-memory) index.

Model Download (2): Automatically download the LLM model: google/flan-t5-small (≈78MB).

RAG Query: Execute the defined RAG query function (rag_query) using the test question: " threshold".











Step 3: View Output
The final cell of the notebook will print the results of the RAG process:

 Question: The query being processed.

 Answer: The response generated by Flan-T5 using the retrieved context, including source citations.

 Sources: A list of the document chunks retrieved by the vector search, along with their page number and retrieval score.

 Precision/📈 Recall: Simple evaluation metrics based on the hardcoded ground truth document.
